# Tohfa downloads

Finished downloads of Zeena and Mawj. Go to [Releases](../../releases/latest) to get them. Mawj is a free demo right now, with every feature on.

**Windows:** download the setup file and open it. Windows may warn you because the app isn't signed yet: choose **More info**, then **Run anyway**.

**Linux:** download the `.tar.gz` file, unpack it, open a terminal in the new folder, and run `bash install.sh`.

Tell us what you think, or report a problem, on the [Issues](../../issues) page.

The source code of these apps isn't published here, and they're not open source. All rights reserved.
